# Ninefold Tattoo

Portfolio sample site for a fictional four-artist tattoo studio on Tib Street in Manchester's
Northern Quarter. One page, static, Astro 5 + Tailwind 4, no accent colour: the ink and skin in
the photographs are the only colour. The footer says it is a sample and that the contact details
are placeholders. Never present it as a real studio.

```
astro.config.mjs   static output, SITE_URL override for the deploy address
build.mjs          checks every photograph exists, builds dist/, zips it to ../../ninefold-tattoo.zip
scripts/           slots.mjs (the shot list) · fetch-images.mjs · prepare-images.mjs · screenshot.mjs · lighthouse.mjs
src/data/site.ts   every word on the page: artists, gallery captions, steps, aftercare, testimonials, form copy
src/images/        the downloaded photographs, one per slot, plus derived/ for the fresh→healed pair
src/components/    Hero · Intro · Work · FreshHealed · Artists · Process · Interstitial · Aftercare · KindWords · Consult · Footer · StickyBar
public/fonts/      Instrument Serif (+ italic) and Instrument Sans, latin subsets, self-hosted and preloaded
public/_headers    long cache for hashed assets on Netlify
reports/           390px screenshot and Lighthouse JSON from the last build
CREDITS.md         photographer credits, generated by the fetch script
```

## Photographs: fetched by script, not committed by hand

The site needs seventeen royalty-free photographs, listed with search queries in
`scripts/slots.mjs`. `pnpm images` searches Unsplash (Pexels as a fallback), scores results
against each slot, downloads the best match at 2400px, verifies it is a JPEG with a long edge of at
least 1600px, and writes `src/images/sources.json` plus `CREDITS.md`. `pnpm images:prepare` then
grades the `healed` photograph twice for the fresh→healed slider, so the comparison is one piece,
not two.

The build that produced this commit could not run that step: the Claude Code cloud environment's
network policy blocked `unsplash.com`, `images.unsplash.com`, `pexels.com` and `images.pexels.com`
(403 at the egress proxy, in both environments on the account). To run it from a cloud session,
open the environment for editing, set **Network access** to **Full**, or to **Custom** with these
lines in **Allowed domains** and "Also include default list of common package managers" ticked:

```
unsplash.com
images.unsplash.com
www.pexels.com
images.pexels.com
```

From a laptop with normal internet access nothing needs changing. Until the photographs exist,
`node build.mjs --allow-standins` builds with gitignored dark stand-ins (`pnpm standins`) for layout
review only and refuses to zip.

## Rebuild

```bash
cd clients/ninefold-tattoo
pnpm install
pnpm images              # download the shot list into src/images/, write CREDITS.md
pnpm images:prepare      # derive src/images/derived/pair-fresh.jpg and pair-healed.jpg
node build.mjs           # dist/ + ninefold-tattoo.zip at the repo root
pnpm shot                # 390px full-page screenshot, image check → reports/
pnpm lighthouse          # mobile Lighthouse, four categories → reports/
pnpm dev                 # local dev server
SITE_URL=https://example.co.uk node build.mjs   # override the deploy URL
```

`ninefold-tattoo.zip` drops straight onto https://app.netlify.com/drop. The consultation form is
wired for Netlify Forms (`data-netlify`, honeypot, `/thanks` for the no-JS path); on any other
host the script falls back to opening the visitor's email app with the enquiry filled in.

## Design notes

- Composed at 390px first. True black `#050505`, bone `#ece7dd`, hairlines `#262626`, no accent.
- Instrument Serif for headings (48px+ on mobile, leading 0.94, tracking −0.025em) with one italic
  word per heading; Instrument Sans for body at 17px and for wide-tracked uppercase labels.
- Sections breathe: 112px vertical padding on mobile, more from tablet up. Full-bleed imagery,
  2px gaps, no cards, no radius. Film grain at 5% on the hero and the interstitial.
- Motion: hero drifts from scale 1 to 1.06 over 20s; everything else is a 600ms fade-and-rise on
  scroll, staggered 90ms, all off under `prefers-reduced-motion`.
- The gallery leads with the large-scale Japanese back piece: the most ambitious work in the set,
  and the piece that survives a full-width crop. It is also the Open Graph image.
- Fresh→Healed is a pointer-driven comparison with a keyboard-operable range input underneath.
- One `h1`, sections labelled by their `h2`, alt text on every image, `TattooParlor` JSON-LD,
  Open Graph and Twitter tags, generated favicon, apple-touch-icon, robots.txt and sitemap.xml.

## Before it goes anywhere near a real studio

- Swap the stock photography for the studio's own healed work, one file per slot in `src/images/`.
- Replace the sample testimonials with real ones, quoted verbatim, and the placeholder contact
  details, hours, deposit and budget bands with the studio's.
- Set the deploy URL (`SITE_URL` or `site` in `astro.config.mjs`) before sharing links.
